# Shoe Store eShop

A simple eCommerce web application for shoes built with Python and Django.

## Features

- Product listing
- Product details
- Admin dashboard
- Image uploads
- User authentication
- Shopping cart (in progress)

## Tech Stack

- Python
- Django
- SQLite
- HTML/CSS
- Bootstrap
- Git & GitHub

## Installation

```bash
git clone https://github.com/eleonora2687/shoe-store.git
cd shoe-store

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
